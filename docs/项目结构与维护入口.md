# 项目结构与维护入口

## 项目依赖

`Ui` 是桌面壳与交互入口；`Pack` 负责战帮编辑和导出；`Packfile` 负责原生包与表编解码；
`Rpfm` 负责外部诊断工具；`Core` 提供目录定位；`Editors` 提供表编辑模型。
命令行验收放在 `tools/WarbandStudio.Probe`，回归测试放在 `tests/WarbandStudio.Tests`。

## UI 模块入口

| 职责 | 文件 |
|---|---|
| 主窗口布局与面板槽位 | `src/WarbandStudio.Ui/MainWindow.xaml` |
| 色彩、字体、间距 | `Themes/Tokens.xaml` |
| 基础控件模板 | `Themes/Controls.xaml` |
| 工作台分组与排版 | `Themes/Workspace.xaml` |
| 门面、包生命周期与画布数据 | `Services/Backend.cs` |
| 成本读取和编辑业务 | `Services/Backend.Costs.cs` |
| 军事组/派系专属归属快照及原版许可读取 | `Services/Backend.MilitaryGroups.cs` |
| 单位军事组状态、专属正向许可归并 | `WarbandStudio.Pack/MilitaryPermissions.cs`、`FactionPermissions.cs` |
| 主视图状态、画布消息与包操作 | `ViewModels/MainViewModel.cs` |
| 工程切换、历史版本、识别清单 | `ViewModels/MainViewModel.Projects.cs` |
| 成本表单、筛选、预览与提交 | `ViewModels/MainViewModel.Costs.cs` |

拆分使用 partial 共享同一实例，保留现有公开接口、编辑集与撤销状态；不创建第二份门面或视图模型。
新增工程操作写入 Projects 模块，成本操作写入 Costs 模块；跨模块仍通过既有门面接口连接。
后续可按画布编辑、素材库、单位查询继续分离，不在无关功能改动中重排所有文件。

## 布局维护

保留左侧工程与素材、中间画布、右侧派系与兵种库的槽位；分栏仍允许拖动。
工具栏按工程、保存、工具分组；状态信息只在底栏显示。
窄窗口下操作换行，欢迎页和全局选项滚动；素材库操作不横向溢出。
主窗口最小尺寸为 1100×700，右侧默认宽度 300。

修改后立即编译；涉及画布时运行两个 canvas 检查；涉及落表时运行原生四项验证。
构建版本后启动验收，日志需出现空状态收尾和 `domCheck bad=[]`。
